The Legend of Zelda: Majora's Mask

    Home Bosses Time Mechanic Masks
    The time mechanic was one of the breakout things for this game compared to others.
    The game revolved around a Three Day Cycle.
    During these three days, the main character is somehow supposed to save the world.
    Obviously there's not enough time to do this.
    The main character uses magic to go back in time to the start of the first day.
    This allows him to be able to save the world in that short time frame.
